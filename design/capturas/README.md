# Capturas

Renders del **sitio ya construido**, tomados con puppeteer sobre el build.
Son fotos: F tiene movimiento y la animación no se ve aquí. Para juzgarla,
corre `pnpm dev` y navégalo.

Se regeneran cuando haga falta; no son fuente de verdad de nada. La fuente de
verdad de la identidad es `design/DESIGN.md` y `src/styles/tokens.css`.
